## Comparison helper

Implement:

```bash
python3 scripts/compare_cpu_warp_results.py \
  --cpu-results outputs/results \
  --warp-results outputs/warp_results \
  --output-csv outputs/cpu_warp_compare.csv
```

Support inputs as either:

- result directories containing per-design JSON files; or
- CSV files generated by existing result collection scripts.

Choose the simplest robust implementation based on current repo structure.

Report:

- overlapping design ids;
- CPU score;
- Warp score;
- absolute score difference;
- relative score difference if meaningful;
- CPU rank;
- Warp rank;
- rank drift;
- failed rows;
- backend;
- score semantics;
- Warp metadata fields if available.

The helper should not claim equivalence. It should report differences.

If overlap is empty, fail clearly.

## Optional GPU smoke test

Add a GPU test file that is skipped by default.

Requirements:

- Do not require CUDA or `mujoco_warp` for normal `pytest -q`.
- Only run real GPU checks when `RUN_GPU_TESTS=1`.
- Skip clearly when `mujoco_warp` is unavailable.
- Skip clearly when no CUDA device is available.
- Keep smoke test small:
  - tiny design;
  - one tool;
  - small `nworld`;
  - few steps or few grasps;
  - no generated outputs committed.

Suggested behavior:

```python
pytestmark = pytest.mark.gpu
```

and runtime guards:

```python
if os.environ.get("RUN_GPU_TESTS") != "1":
    pytest.skip("set RUN_GPU_TESTS=1 to run optional GPU tests")
```
